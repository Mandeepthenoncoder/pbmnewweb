# Pearls by Mangatrai — new website prototype

Static HTML/CSS/JS prototype of the conversion-focused redesign, built before porting to Shopify.

- **Live preview:** https://mandeepthenoncoder.github.io/pbmnewweb/
- Pages: `prototype/index.html` (home), `collection.html`, `product.html?handle=…`, `landing.html` (Meta ads), `cart.html`, `checkout.html` (mock), `account.html`, `wishlist.html`, `about.html`, `education.html`, `contact.html`, `faq.html`, `shipping-returns.html`, `policies.html`
- Research and Shopify mapping: `CRO-Research-and-Plan.md`

Product data and images are pulled from the live store's public catalog. Cart, wishlist, promo codes and the "Try your luck" game run in the browser (localStorage) for review only.
